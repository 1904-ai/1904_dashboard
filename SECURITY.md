# Security policy

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/1904-ai/1904_dashboard/security/advisories/new) or [1904's contact form](https://1904.ai/contact). Identify the product as **1904 Desktop** and mention if the issue also affects the hosted dashboard. Keep vulnerability details out of public issues, pull requests, and comments.

Include the affected version and operating system, steps to reproduce the issue, and the impact you observed. Redact account details, session cookies, tokens, and private task content. If the report needs sensitive material, request a secure way to share it.

Please coordinate public disclosure with the maintainers so they can investigate and address the issue.
