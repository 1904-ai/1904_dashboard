1904 Desktop Browser Extension
==============================

These files are the unpacked Chrome / Edge extension used by 1904 Desktop.
You do not need to open or edit any individual file inside this folder.

How to install (one-time setup):
1. Open Chrome or Edge and go to chrome://extensions (or edge://extensions).
2. Turn on "Developer mode" in the top-right corner.
3. Click "Load unpacked" and select this entire "1904-browser-extension" folder.
4. Go back to 1904 Desktop's "Connect your browser" window and copy your pairing code.
5. Open the signed-in website tab you want to share, click the 1904 Desktop Browser
   extension in your toolbar, paste the pairing code, and click "Share this tab".
