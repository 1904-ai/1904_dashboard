1

Install the 1904 extension in Chrome or Edge

One-time setup

Until the extension is on the browser store, Chrome and Edge load it from a folder on your computer.

  1. Open your browser’s extensions page by pasting chrome://extensions (or edge://extensions) into the address bar.

  2. Turn on Developer mode (top-right toggle).
  3. Click Load unpacked, then select the 1904-browser-extension folder itself (you do not need to open the files inside it).

Already installed? Skip to step 2. After updating 1904 Desktop, click Reload on the extension card.

2

Copy your pairing code

Paste this code into the 1904 Desktop Browser extension popup — not your browser’s address bar. It is a temporary code for this session, not a web link.

3

Share a signed-in tab

  1. Switch to the Chrome or Edge tab you want 1904 to use (a public website).
  2. Click the Extensions puzzle icon in your browser toolbar and open 1904 Desktop Browser.
  3. Paste the pairing code and click Share this tab.
  4. This window updates automatically once connected. 1904 Desktop still asks before each task uses the tab.

Cookies stay in your browser. Safari and Firefox are not supported yet.
